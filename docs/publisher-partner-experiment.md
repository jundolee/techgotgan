# 발행처 직접 연락 아이디어 — 중단

작성일: 2026-11-11
상태: 사용 금지. 사용자가 회사에 연락하는 것을 금지했다.

## 적용할 제한

- 회사, 블로그 편집자, 기사 작성자에게 이메일·DM·공유 요청·제휴 제안을 보내지 않는다.
- 이전에 준비했던 연락 문안과 발행처별 파트너 UTM은 사용하지 않는다.
- 이 문서를 따라 외부 연락을 진행하지 않는다.

## 연락 없이 진행할 유입 경로

1. **자사 채널:** Velog 글과 개인 블로그 글에서 공개된 `/cases` 페이지로 연결한다. 글마다 UTM을 분리해 어느 링크가 방문을 만드는지 본다.
2. **독자 간 공유:** `/cases`의 회의 질문 공유를 제공한다. 수신자의 UTM 방문, 사례 열기, 원문 이동을 확인한다.
3. **문제 중심 진입:** `/cases`의 고정 문제 유형 선택을 통해 비개발자도 자신이 겪는 문제에서 출발하도록 한다. 선택 이벤트는 고정된 세 범주만 기록한다.
4. **검색 유입:** 실제 노출과 쿼리가 쌓인 페이지에 한해 제목·본문을 조정한다. sitemap 등록이나 URL 제출만으로 성과를 판단하지 않는다.

## 현재 기록

- 직접 연락이나 공유 요청은 보내지 않았다.
- 회사별 허브와 사례 페이지는 방문자가 스스로 찾고 공유할 수 있는 공개 페이지로 유지한다.
- 외부 유입 판단에는 사용자 소유 채널의 UTM, 검색 후 사례 열기, 원문 이동, 재방문을 사용한다.
