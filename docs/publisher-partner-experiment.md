# 원문 발행처와 함께하는 사례 공유 실험

작성일: 2026-11-11
상태: 공유 자료와 추적 링크 준비 완료. 외부 연락은 보내지 않음.

## 왜 다른 경로인가

테크곳간의 사례는 외부 회사 기술 블로그 글을 요약해 원문으로 연결한다. 원문 발행처가 이를 공유하면 독자는 관심 주제의 사례를 더 쉽게 찾고, 발행처는 자기 글로 이어지는 추가 진입점을 얻는다. 이 상호 이익이 실제 공유로 이어지는지 확인한다.

일반적인 서비스 홍보 요청이 아니라, 발행처를 명시하고 원문을 전면에 둔 **회사별 글 모음 페이지**를 먼저 제공한다. 반응 여부를 확인하기 전에는 협업, 제휴, 공동 홍보라고 표현하지 않는다.

## 공유 문안 초안

> 안녕하세요. 공개 기술 글을 회사와 주제별로 찾고 원문까지 이어볼 수 있도록 테크곳간을 운영하고 있습니다. 귀사의 공개 글도 회사별 페이지에 출처와 함께 모아두었습니다. 최신 글을 확인하시거나, 목록·출처가 잘못된 부분이 있으면 알려주세요. 유용하다면 독자에게 공유하셔도 됩니다. 원문은 각 글에서 바로 열 수 있습니다.
>
> [해당 회사의 글 모음 링크]

이 문안은 검토 초안이다. 아직 발송하지 않았다. 공개 내용의 정정이나 삭제 요청이 오면 먼저 반영한다.

## 14일 관찰

- **대상 행동:** 발행처가 공유 링크를 실제로 배포하는지, 링크를 받은 사람이 테크곳간에 방문하는지, 원문까지 이동하는지.
- **측정:** 게시물 노출·클릭은 발행처가 제공하는 자료가 있을 때만 기록한다. 테크곳간에서는 발행처별 UTM 세션, 회사별 허브 진입, `article_click`, `source_article_click`, 7일 재방문을 분리한다.
- **판정:** UTM 방문만으로 협력 성과라고 하지 않는다. 원문 이동이나 재방문을 함께 본다. 발행처 도달 자료가 없으면 미공유라고 단정하지 않는다.
- **중단 기준:** 공개된 협업 의사나 링크 공유 없이 단순히 발송한 사실만 남으면 추가 발송을 늘리지 않고, 먼저 문안과 발행처 혜택을 다시 검토한다.

## 경계

- 현재는 준비 상태이며 발행처와 연락하거나 게시를 요청하지 않았다.
- 회사가 공식 추천·승인·제휴했다고 표현하지 않는다.
- 회사별 캠페인 세션, 실제 원문 이동, 재방문이 확인되기 전에는 유입 성공으로 보고하지 않는다.
