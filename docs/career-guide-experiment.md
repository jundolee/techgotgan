# 기업별 취업 준비 가이드 실험

- 가설: 토스 프론트엔드 지원에 관심 있는 사람은 회사가 공개한 자료와 읽기 질문을 모은 페이지에서 원문을 찾아보고 유용성을 평가한다.
- 대상: 토스 프론트엔드 지원 또는 기업 조사에 관심 있는 개발자. 페이지는 테크곳간이 독립적으로 편집했고 공식 채용 안내가 아니다.
- 노출: 공개 블로그 목록과 GitHub README. README 링크는 `utm_source=github`, `utm_medium=readme`, `utm_campaign=career_guide_toss_frontend`를 사용한다.
- 관찰: 배포 시점부터 14일간 GA4에서 페이지 경로별 사용자와 유입 채널을 확인한다. Amplitude `page_viewed`의 `page_path`와 `career_guide_interaction`의 `guide=toss_frontend`, `action=source_click` 또는 `feedback`, `detail`로 원문 클릭과 자발적인 피드백을 본다. 테스트 방문은 분석 시 제외하거나 별도로 기록한다.
- 판단: 최소 30명의 실사용자가 방문한 뒤 원문 클릭 사용자 비율, 자발적인 피드백의 내용과 맥락, 채널별 유입을 함께 검토한다. 표본이 적으면 성공이나 실패로 단정하지 않고 관찰 기간을 연장한다. 클릭은 관심의 신호일 뿐 취업 준비에 실질적으로 도움이 됐다는 증거는 아니다.
- 제한: 피드백은 익명 이벤트이며 한 사용자당 한 번으로 제한되지 않는다. 운영 환경에서 분석이 켜져 있고 이벤트가 실제 도착하는지 확인해야 한다. 자연 검색 유입은 색인 여부와 반영 시간에 따라 늦을 수 있다.
